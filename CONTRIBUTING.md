# Contributing

Contributions and bug reports are welcome.

## Before submitting a change

1. Search existing issues and pull requests to avoid duplicate work.
2. For substantial changes, open an issue first to discuss the approach.
3. Keep changes focused and avoid committing generated build output, local
   configuration, signing credentials, or Xcode user data.
4. Test the affected sender or receiver on the relevant physical device when
   possible.

## Pull requests

Describe what changed, why it changed, and how it was tested. Include device and
OS versions when behavior is platform-specific. Screenshots or recordings are
helpful for user-interface changes.
